# Product Spec

## 目标

Paper AI Reader 是一个本地优先的论文阅读器。第一阶段目标是把文献导入、PDF 阅读和 AI 精读的主流程打通，保持轻量、可维护，并为后续桌面端封装预留空间。

## 第一阶段功能

### 文献管理

- 导入本地 PDF。
- 自动保存文件、计算哈希，避免重复导入。
- 维护标题、作者、年份、DOI、摘要、标签和集合。
- 支持按关键词搜索文献。

### PDF 阅读

- 在 Web 内打开 PDF。
- 支持页码、缩放、适宽、搜索等阅读器基础能力。
- 为高亮、笔记、区域标注预留数据模型。

### AI 精读

- 使用 PyMuPDF 提取 PDF 文本。
- 将正文按页和 token 预算切分为 chunk。
- 用 Chroma 或本地向量索引保存嵌入。
- 支持摘要、章节解释、术语解释、问答和引用定位。

## 非目标

- 第一阶段不做账号系统。
- 第一阶段不依赖云端数据库。
- 第一阶段不强制接入付费模型。

## 后续路线

1. PDF.js 阅读器集成。
2. 文献导入与元数据编辑完整闭环。
3. 标注和笔记同步到 SQLite。
4. PyMuPDF 文本抽取和 chunk 入库。
5. Ollama / OpenAI-compatible API 统一模型适配层。
6. Chroma 向量索引和 RAG 问答。
7. Tauri 桌面端封装。
